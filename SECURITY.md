# Política de seguridad

## Versiones con soporte

Solo se ofrece soporte de seguridad para la versión oficial más reciente de **Calculadora PAU Andalucía (2026)** publicada en el repositorio oficial o en los canales oficiales de distribución del proyecto.

| Versión | Soporte de seguridad |
| ------- | -------------------- |
| Beta-1.0 | :white_check_mark: |
| Versiones anteriores | :x: |
| Versiones modificadas por terceros | :x: |

Las versiones modificadas, redistribuidas o empaquetadas por terceros no se consideran versiones oficiales del proyecto. La responsabilidad sobre dichas versiones corresponde a quien las haya modificado, compilado, empaquetado o distribuido.

## Avisar de una vulnerabilidad

Si encuentras una vulnerabilidad, fallo de seguridad o comportamiento que pueda comprometer la integridad del programa, del ejecutable, de los archivos distribuidos o de los datos generados, puedes comunicarlo por correo electrónico a:

**alopper8@gmail.com**

Por favor, incluye en el mensaje, si es posible:

- Una descripción clara del problema.
- Los pasos necesarios para reproducirlo.
- La versión del programa afectada.
- El sistema operativo utilizado.
- Capturas, mensajes de error o archivos de ejemplo, siempre que no contengan datos personales o información sensible.

No publiques vulnerabilidades graves directamente en los Issues públicos de GitHub si el problema puede ser aprovechado por terceros antes de ser corregido.

Una vez recibido el aviso, se revisará el problema y, si procede, se publicará una corrección o una nueva versión oficial. No se garantiza un plazo concreto de respuesta o resolución.

## Alcance

Esta política se aplica únicamente a la versión oficial de **Calculadora PAU Andalucía (2026)** publicada por Álvaro López Pérez.

Quedan fuera del alcance de esta política:

- Versiones modificadas por terceros.
- Ejecutables no oficiales.
- Redistribuciones no autorizadas o alteradas.
- Problemas derivados de dependencias, sistemas operativos o configuraciones externas no controladas por el proyecto.
- Usos contrarios a la licencia del proyecto.

## Actualizaciones de seguridad

Las correcciones de seguridad, cuando sean necesarias, se publicarán mediante nuevas versiones oficiales del proyecto.

Se recomienda descargar el programa únicamente desde las fuentes oficiales indicadas en el repositorio y en la documentación del proyecto.
